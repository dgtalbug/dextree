# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Enforcement contact

Reports of conduct concerns may be sent to `dgtalbug@gmail.com` with the
subject prefix `[dextree conduct]`. Reports are handled confidentially.

For security vulnerabilities, use the private channel described in
[SECURITY.md](SECURITY.md) instead of this address.
